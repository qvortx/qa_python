# qa_python

## Описание

Проект содержит тесты для класса `BooksCollector`.

Тесты написаны с использованием `pytest` и проверяют основные методы приложения по добавлению книг, работе с жанрами и избранным.

## Реализованные тесты

В проекте реализованы следующие проверки:

1. Проверка добавления новой книги.
2. Проверка добавления разных книг с использованием параметризации.
3. Проверка установки допустимых жанров с использованием параметризации.
4. Проверка получения жанра книги.
5. Проверка получения книг с определённым жанром.
6. Проверка получения словаря книг и их жанров.
7. Проверка получения книг, подходящих для детей.
8. Проверка добавления книги в избранное.
9. Проверка удаления книги из избранного.
10. Проверка получения списка избранных книг.

## Параметризация

В тестах используется параметризация `pytest.mark.parametrize` для проверки нескольких вариантов входных данных без дублирования тестового кода.

Параметризация применяется для:

- проверки добавления разных книг;
- проверки установки различных допустимых жанров.
